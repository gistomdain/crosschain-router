# Crosschain Router

A responsive cross-chain route comparison and execution interface.

## Build 01
- Swap/bridge interface
- Route Intelligence panel
- Demo normalized quotes for Relay, Across, LI.FI and deBridge
- Quote API scaffold at `/api/quote`
- Responsive mobile layout
- Non-custodial UX foundation

Quotes are illustrative until live provider adapters and wallet execution are enabled.

## Run
```bash
npm install
npm run dev
```

## Next
Wallet connectivity, live provider adapters, token/chain selectors, quote expiry and re-quote protection, execution, transaction tracking, destination actions and recovery.
